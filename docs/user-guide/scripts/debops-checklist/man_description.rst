Description
===========

The :command:`debops checklist` subcommand provides a simple management
interface for checklists in the form of Markdown documents with `GitHub
Flavored Markdown`__ format used for the tasks theselves.

.. __: https://github.github.com/gfm/

Multiple checklist copies can be opened at once, edited and committed in the
DebOps project directory as records.

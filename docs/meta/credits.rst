Credits
=======

The :file:`CREDITS` file included below is generated from the git
commit history of the project by the :command:`make credits` command.
Its contents are configured in the :file:`lib/credits/credits.yml`
file. The generated file is included in the released Python packages
and the DebOps Ansible Collection, and in the root of the repository
on each release tag.
